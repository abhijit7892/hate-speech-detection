# hate-speech-detection
NLP model detects hate speech using TF-IDF Logistic Regression gained 87% accuracy on 10k+ tweets.
## classification
classify tweets into 3 categories Hate Speech, Offensive language, Neither Hate nor offensive language.
## Library 
python,Scikit-learn,NLTK,Numpy,Pandas,Matplotlib,Seaborn.
Machine learning tools- Logistic Regression,TF-IDF.
## Dataset
Size:24,783 labelled tweets.
Source:Kaggle dataset.
Splitting:70% Train(17,348) ,30% Test(7,435) with random state=42.
Classes:Hate Speech,Offensive language,Neither 
Features:TF-IDF Vectors with 25,693.
